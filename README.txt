HEART SVM FRONTEND

Files:
- index.html: user interface
- style.css: responsive dashboard styling
- app.js: browser-side SVM inference
- model-data.json: support vectors and preprocessing values extracted from the uploaded trained pipelines

Run:
Keep all four files in the same folder. Open using a local static server (recommended) or deploy the folder to GitHub Pages. Fetch() may be blocked when opening index.html directly as file://.

No backend is used. All inference is performed in the browser with JavaScript.

IMPORTANT:
This is an educational machine-learning demonstration, not a medical diagnostic tool. Predictions should not be used for medical decisions.
